# Hi, I'm Goodnews 👋

### Electrical & Electronics Engineer | Researcher | Embedded Systems

I'm an Electrical & Electronics Engineer interested in building intelligent hardware and sensing systems that connect electronics, computation, and the physical world.

My current interests sit at the intersection of:

* **Intelligent Sensing**
* **Microelectronics**
* **Wireless & Optical Systems**

### 🔬 Research Interests

My work explores sensing and embedded systems, optical wireless technologies, electronics design, and the application of machine learning to intelligent physical systems.

### 🚀 Selected Projects

**[ML-Based Visible Light Positioning](https://github.com/eru-dite/ML-Based-VLP)**
Machine learning models for estimating indoor position from visible-light signal measurements.

**[Visible Light Communication for Indoor Positioning](https://github.com/eru-dite/Visible-Light-Communication-for-Indoor-Positioning)**
Experimental VLC/VLP system using modulated LEDs, photodetection, and embedded signal processing.

**Analog Circuit Design**
Hands-on exploration of analog IC design, SPICE simulation, and open-source semiconductor design tools.

### 📚 Publications

**AquaSense: Intelligent Water Quality Monitoring System**
Low-cost IoT-based water-quality monitoring system with machine-learning-based pollution classification.

**Design and Implementation of a Mobile Solar Phone Charger for Rural Communities in Nigeria**
Research on a solar-powered charging system using embedded control and power electronics.
